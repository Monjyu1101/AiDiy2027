# 更新の目印と銀河の光輪表示

## 判定と表示

`frontend_ide/src/components/ファイル閲覧/更新の目印.js` が2Dと3Dの共通判定を持つ。入力は現在フォルダ直下の、フィルター適用後のファイルだけとする。子フォルダ内の日時や除外されたファイルを最新候補へ混ぜない。

- ブラウザのローカル暦日で今日を判定する。日付の境界は `setHours` / `setDate` を使い、夏時間の日を24時間固定で計算しない。
- 今日のうち最も新しい更新日時を本日最新とする。同率はすべて最新扱い。今日のファイルがなければ今日・最新の強調は付けない。
- 2Dは今日を薄い縁、最新を少し強い縁で表示する。種類別アイコン、文字色、赤い「今日」、フォルダ色、選択・hoverの背景を上書きしない。
- 3Dの直下ファイルは、本日更新を薄い黄色、本日最新を金色の光輪とラベルで示す。前日以前は通常表示。電子・衛星の周回表示は使わない。
- 初回、フォルダ・フィルター・セッション切替は基準を取り直し、発光させない。同じ対象内の追加、mtimeまたはsize変更だけを1.2秒の弱い発光で示す。削除済み対象には発光を残さない。無差分更新で発光を再開しない。
- 深夜と非表示からの復帰時に再判定する。既存の2D監視は応答完了から30秒間隔を維持し、この表示処理は新たな走査要求を増やさない。

## 描画の担当

`開発スペース/宇宙描画.js` の既存Canvas 2Dで描く。`RECENCY` と共有の `RECENCY_HALO` スプライトを使い、星の縁から外側へ薄くなる光輪と「本日更新」「最終更新」のラベルを表示する。更新時の発光は同じ描画内で合成する。

電子専用のWebGL層・頂点バッファ・追加RAFは使用しない。2D・非表示では既存の3Dループを止める。OSの動作設定を理由に規定の更新表示・発光を抑えない。終了時は既存の購読・期限タイマーを解放する。旧電子表示の2,048ファイル・8,192電子等の上限を現行の光輪へ転用しない。実機のCPU/GPU負荷は別途測定する。

## 確認

`frontend_ide` で以下を実行する。ブラウザ確認前は明示的にビルドする（単独サーバーはdistを配信する）。

```powershell
node --test checks/update-marks.test.mjs checks/star-depth.test.mjs checks/folder-pages.test.mjs checks/file-dates.test.mjs checks/folder-monitor.test.mjs checks/navigation-parity.test.mjs
node scripts/build.mjs
node scripts/check-update-marks.mjs
```

ブラウザスクリプトは一時プロジェクトと隔離Chrome/Edgeを使う。AIや外部APIへ送信しない。今日/最新同率、変更行だけの発光、日跨ぎ、移動、2Dの更新強調と3Dの光輪・ラベルを検証し、`temp/update-marks-check/` に画面と結果を保存する。日時テストはUTC、東京、ニューヨークの年跨ぎ・夏時間境界を含む。
