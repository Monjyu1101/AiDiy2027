# AiDiy IDE

現行画面は `frontend_ide` のVue共通部品です。`aidiy_ide` の起動コマンドを維持します（IDE自身のVS Code拡張はありません）。共通画面の変更・起動手順は [frontend_ide README](../README.md) を参照してください。本書は現行のファイルAPI・文書表示・宇宙描画の補足です。

AiDiy の **開発スペース**（宇宙をテーマにした IDE 開発環境）の中心となる、作業フォルダを宇宙の見た目で眺めて操作するファイルビューアです。Code / Live とともに、AiDiy の正式なサブシステムを構成します。
目指すのは「ソースをほぼ触らない IDE」です。宇宙で全体を眺め、エクスプローラーで辿り、ビューアで読み、変更は Code / Live を通じて AI に任せます。
ルートのsetup / cleanupではIDE群（Navi / Console / Code / Live / IDE / Task / Team / Browser）として扱います。全体startはDiagを使わない場合にIDEを個別選択できます（既定OFF）。
起動時は Live と同じターミナル演出の初期画面を表示します。「AiDiy接続利用」または「オフライン利用」を手動で選んで宇宙表示を開始します。

見た目は宇宙のテーマですが、画面の文字は「フォルダ」「ファイル」など一般的な名前で表示します。

## 見え方

入口は起動したプロジェクトフォルダです。いつも1階層だけを表示します。中央の3D原点から直下の銀河・ファイルへ薄い直線を引き、つながりを示します。

| 見た目 | 表すもの |
|---|---|
| 銀河 | 直下のフォルダ。星の数は配下の全ファイル数。24個未満は楕円、それ以上は2〜4本腕の渦巻き |
| 銀河の星 | フォルダ配下のファイル。色は種類、大きさはファイルサイズ、明るさは更新の新しさ |
| 惑星 | 直下のファイル。名前で決まる3D空間内の固定位置 |
| 速い明滅（十字の光） | 時刻検索の指定期間に更新したファイル |
| ゆっくり明滅する銀河 | 時刻検索の指定期間に更新したファイルを含むフォルダ（名前が金色になり、一覧にも「更新 N」） |
| 渦（ワームホール） | 1つ上のフォルダへ戻る入口 |
| 金色の点線 | このフォルダで開いた・選んだ順の移動経路 |

## 操作

- クリック: 中央のフォルダを選択 / ファイルへズームして右にプレビュー（中央のフォルダは視点を動かさない）
- ダブルクリック: 中央のフォルダへワープ / ワームホールから親へワープ / ファイルへフォーカス
- Esc: 表示中のビューアを閉じ、選択がなければ親フォルダへ。Backspace / 下のパンくず / ブラウザの戻るでも親へ移動
- 左上の ☰ / `Ctrl+B`: フローティング表示のエクスプローラー（VS Code 風のファイルツリー）を開閉。起動時・利用開始時は常に閉じた状態で、バーガーだけを表示します。開いているフォルダの展開状態だけを記憶し、プレビューがない時は開閉で宇宙の位置を変えません。ファイルのクリックでその場所へ移動して右側に中身を表示、フォルダ名はクリックでワープ移動、▸／▾は開閉。↑↓←→ / Home / End / Enter でも操作できます。宇宙で選んだ場所はツリーでも自動で開いて表示します
- 右側: ファイルを選ぶと右半分にポップアップで中身を表示し、選択対象は空き領域の中央へズームします。エクスプローラーを閉じている時は左から25%、開いている時はエクスプローラー右端とプレビュー左端の中間を計算します（1280px幅なら約39%）。パネル開閉に応じて空き領域へ視線を合わせます。コードは Monaco Editor、画像はそのまま、Office文書・PDFは専用ビューアで表示します。空白クリック・✕ / Escで解除し、現在の階層・船体位置・船首方向を保ちます。フォルダ一覧は左のエクスプローラーにまとめています。
- 時刻検索: 「起動」「10分」「1時間」「今日」「解除」の5種類。既定の「起動」はAiDiy接続成立時刻（オフラインは利用開始時刻）からの更新をマークします。「10分」「1時間」は押した時点から遡った時刻、「今日」は当日0:00、「解除」はマークなしです。「開始」「終了」に年月日・時分秒を入力できます。終了が空なら開始以降、指定時はその秒の末尾までを検索し、マークと「時刻軌跡」に反映します。開始より前の終了や不正な日時はエラーです。開始のプリセットは終了を維持し、「解除」は両方を空にします。新しい利用開始時は「起動」に戻り、終了を空にします。更新内容は R で再読み込みします。
- grep検索（時刻検索との切り替え）: プロジェクト全体のテキスト内容を文字列の部分一致で検索し、一致ファイルと親フォルダを金色・●でマークします。宇宙の星も同じ対象が明滅します。「大文字・小文字を区別」を選択でき、検索語の変更・解除で古いマークを消します。一致ファイルの親フォルダは自動展開します。
- grepはUTF-8 / Shift_JISの1MB以下のテキストが対象です。依存物・生成物・.aidiy_backup・旧.backup_local・.aidiy_cache・外部リンク・画像・Office文書・PDF・バイナリは検索しません。最大30,000ファイル、読込256MB、30秒で打ち切り、対象外件数と一部結果であることを画面に表示します。
- Spaceで自動探索を切り替え、Rで再読み込み。自動探索は手動操作後の1分間と手動で選んだファイルの表示中には割り込みません
- ドラッグで画面中央を軸に回転、右ドラッグ（Shift+ドラッグ）で移動、Ctrl＋マウスホイールでズーム（通常のホイールではズームしません）。中央下の視点操作ボタン・XYZ軸は表示しません

今のフォルダは URL の `#/フォルダ/…` に反映されるので、ブックマークからそのフォルダを直接開けます。
移動経路・履歴はブラウザ（localStorage）にプロジェクトごとに保存します。時刻検索の開始・終了は利用中だけ保持し、画面の再読み込み時は開始に同じ接続開始時刻、終了に空欄を使います。

## セットアップと起動

Node.js 22.13 以降を使用します。Electron、コード表示の `monaco-editor` と文書表示ライブラリを、このフォルダの依存として導入します。更新後はセットアップを再実行し、AiDiy IDE のサーバーも再起動してください。Codespaces・画面のない Linux では Electron 本体の取得を省略します。

```powershell
python _setup.py                          # 全体セットアップ（IDE群を選ぶ）
python frontend_ide/_setup.py              # 共通Vue画面・viewer依存・IDE群のコマンドを準備
aidiy_ide                                 # 今いるフォルダをプロジェクトとして Electron 起動
aidiy_ide C:\work\project                 # フォルダを指定
aidiy_ide --project C:\work\project       # 明示オプションでも指定可能
aidiy_ide --browser                       # Web 版を明示して起動
python _start.py                          # Diagを使わない場合、IDEを選択してリポジトリ直下を表示
node frontend_ide/viewer\launch.mjs . --no-open   # サーバーだけ起動
```

- 通常は Electron の専用ウィンドウを独立プロセスで開き、コマンドプロンプトへ戻ります。窓を閉じると、そのプロジェクトのサーバーも終了します。`--foreground` / `--wait` 指定時は起動中のまま待機し、Ctrl+Cでも終了できます。
- Codespaces・画面のないLinuxはWebで開きます。Electron起動失敗時のWeb切り替えは前景起動時だけで、通常の分離起動では失敗を報告します。`--browser` でも指定できます。Web 版は Ctrl+C で終了します。
- ポート番号は固定せず、起動ごとに OS が空きポートを割り当てます。画面は起動ログの URL で開きます。番号が必要な場合だけ `--port 番号`（厳密指定は `--strict-port` を併用）を渡します。Codespaces では実際に割り当てたポートの転送 URL を表示し、`$BROWSER` へ localhost URL を渡して VS Code に転送を任せます。「ポート」から開くこともできます。転送先は環境変数で特定した当該 Codespace だけを許可します。
- Diagを使わない全体起動では、選択したTask / Team、Console / Code / Live / IDE、Discord / Slackを順に扱います。IDE は空きポートで独立起動し、ログを配置先リポジトリの `temp/aidiy_ide/logs/` に保存します。共通起動を使う Console / Task / Team / Browser も `temp/aidiy_<kind>/logs/` へ起動ごとの UUID 名で保存します。旧 `viewer/out/` のログは移行・削除せず、新保存先に書けない場合も旧保存先へ退避しません。Electron の設定・認証・プロファイルは変更しません。全体起動の起動前整理・Ctrl+C・リブートでは停止せず、自動再起動もしません。クリーンアップ（`python _cleanup.py`）はこの配置先のプロセスを照合して停止し、`aidiy_ide` コマンド解除・`node_modules` 削除を行います。
- `node_modules`、`.git`、`dist`、`.venv`、`_cache` などは表示しません（`file-scan.mjs` と `../ファイル機能/フォルダ除外規則.mjs` の共通規則）。

## AiDiyへの接続

- 初期画面で「AiDiy接続利用」「オフライン利用」のどちらかを選びます。自動開始はせず、初回接続失敗も手動で再試行します。利用前はファイルビューアを隠し、ファイル取得 API を 503 で停止します。
- 接続先は AiDiy 配置先を優先して `_config/AiDiy_key.json` の `PORT_TOOLS` を読み、ホストは `127.0.0.1` に固定します。設定がなければ 8095 です。設定ファイルのキー情報は画面へ返しません。
- IDEはConsoleと同じ `GET /aidiy_code_agents/ping` で稼働を確認し、`status: "ok"` と `name: "aidiy_code_agents"` を確認します。Code / Live 子パネルの接続先は従来どおり `PORT_CORE` です。
- AiDiy接続利用: toolsの応答を確認して開始し、上部のシアンバーが Live と同じ4.5秒周期で明滅します。10秒ごとにtoolsを確認（応答期限1.5秒）します。tools停止中もファイル表示・ファイル API・Code子窓・作業起点を維持し、復帰時に同じセッションで再接続します。
- オフライン利用: コアに接続せずファイルビューアを利用でき、同じバーが赤で明滅します。toolsの状態確認も行いません。
- 「終了」（Web版は「利用終了」）でCode / Liveを停止して起動画面に戻り、利用方法を選び直せます。Electron版のタイトルバーの×は、利用中だけ「AiDiy IDE を終了しますか？」の確認後にIDE全体を終了します。初期画面・起動画面へ戻った後は確認せずに終了します。
- Codespaces でもtoolsは IDE サーバーと同じ環境で起動します。ブラウザは IDE サーバーの転送ポートに接続するため、ブラウザ側からtoolsの localhost へ接続する必要はありません。

## Code / Live パネル

Electron版は「＋ Code」「＋ Live」で同じプロジェクト・利用セッションの別ウィンドウを開きます。Web版は画面内タブで切り替えます。

- AiDiy接続利用では既存のCodeとLiveを利用できます。Liveの接続・マイク・スピーカーはパネル内で手動操作します。
- オフライン利用ではLiveの起動ボタン・タブを表示しません。既存Codeと同じHermes直接実行で、AIコアへの接続は不要です。選択したAIサービスやCLIの認証・通信は必要です。
- Web版のCodeパネルは非表示にしても入力や会話を維持します。Liveを閉じる／Codeタブへ切り替えると音声と接続を終了します。「利用終了」は両パネルと実行を終了します。コアの接続断ではIDEの作業セッションとCodeパネル・子窓を維持します。
- Code / Live は `frontend_ide/host` のセットアップ済み成果物を使います。IDEの公開元で中継するため、Codespacesで追加のポート転送は不要です。

## 構成

Office文書の対応形式・表示の制限・検証方法は [文書ビューア手順](../../_AIDIY/knowledge/frontend_ide,文書ビューア.md) を参照してください。

- Word: `.docx` / `.dotx`（ページ表示・倍率変更）。
- Excel: `.xlsx` / `.xls` / `.xlsm` / `.ods` / `.csv` / `.tsv`（シート切り替え、200行ずつ表示、結合セル・保存済みの計算結果）。
- PowerPoint: `.pptx` / `.pptm`（スライド送り・倍率変更）。
- PDF: `.pdf`（ページ送り・倍率変更）。

VS Code の [Office Viewer](https://github.com/cweijan/vscode-office) が採用・紹介する表示ライブラリを利用しています。VS Code 拡張自体の移植ではなく、AiDiy IDE 用の読み取り専用 UI です。文書は外部変換サービスへ送信せず、ローカルで表示します。複雑な書式・図形は元のOfficeアプリと表示が異なる場合があります。旧形式の `.doc` / `.ppt`、パスワード付き文書は対象外です。

- `_setup.py` / `_start.py` / `_cleanup.py` / `launcher.py`: セットアップ・起動・クリーンアップと `aidiy_ide` コマンド
- `launch.mjs`: `../launch.mjs` へ進む互換入口。`launch-options.mjs` は作業フォルダ・転送先URL・Electron / Web判定を共通提供
- `core-connection.mjs`: AiDiy toolsの接続確認
- `server.mjs` / `file-scan.mjs`: フォルダ走査（`/api/galaxy`）、ファイルの中身（`/api/file`・`/api/raw`・`/api/document`）、エクスプローラー操作の受付、Monacoと文書ビューアの配信。コピー・名前変更・新規作成・ゴミ箱移動は `../ファイル機能/explorer-files.mjs` に委譲
- 画面: `frontend_ide/src/` の Vue 画面（`frontend_ide/server.mjs` が配信）。`web/layout.js` の3D配置を取り込みます。
- `web/office.html` / `office.js` / `office.css`: 独立した iframe 内で表示する文書ビューア。
- `checks/`: 文書API・アクセス境界の自動テストと検証用データ生成。
- `scripts/shot.mjs`: 画面確認用のスクリーンショット（ヘッドレス Chrome）

設計方針と実装入口は [`AGENTS.md`](./AGENTS.md) にまとめています。

## 名前から決まる3D空間

フォルダ名・ファイル名を Unicode NFC で正規化し、用途を分けた3つのハッシュ値を作ります。値を `u, v, w`（各0以上1未満）とすると、次の球座標変換で毎回同じXYZ座標になります。

```text
方位角 θ = 2πu
高さ方向 h = 2v - 1
中心からの距離 r = 表示半径 × ∛(0.008 + 0.992w)
x = r × √(1-h²) × cosθ
y = r × h
z = r × √(1-h²) × sinθ
```

FNV-1a と最終混合によって似た名前を分散させます。半径の立方根で球の体積に沿って広げ、中心は帰還ゲートのために少し空けます。銀河内部の同名ファイルは相対パスも使って区別します。3D座標を透視投影し、遠近による大きさの違いと回転時の視差で奥行きを表現します。

件数・列挙順・サイズ・更新日時は位置計算に使いません。ファイルの増減でも既存座標と全景倍率を維持します。名前を変更すると位置も変わります。どの視点でも全ラベルが重ならないことまでは保証しないため、回転・ズーム・左のツリーを併用してください。

- ドラッグ: 上下左右へ360度回転（上下の極でも止まらない）。
- 右ドラッグ / Shift+ドラッグ: 画面に沿って平行移動。
- Ctrl+ホイール: ズーム。通常のホイールではズームしません。
- 「自動探索」/ Space: 自動飛行と最終更新ファイルの追跡を切り替えます。旧画面の矢印・XYZ軸は表示しません。

星そのものは移動せず、更新の明滅だけ残します。訪問済みフォルダの視点を保持します。

## ファイルの選択・解除

星のクリックと一覧のファイル選択は同じ動作です。選んだ星へズームし、右側にプレビューを表示します。別階層のファイルを選んだ場合は、その階層へワープしてからズームします。

空白クリック・プレビューの「×」・Escで選択を解除しても、到着した階層・船体位置・船首方向を保ちます。移動中ならその場で停止し、元のフォルダへ自動では戻りません。

## フォルダ移動のワープ演出

中央のフォルダとワームホールはダブルクリックで移動します。フォルダ一覧では名前を1回選ぶと、そのフォルダ内へ同じワープ演出で移動します。行頭の「▸／▾」はツリーの開閉専用です。Enterキーでのフォルダ選択や検索結果からのフォルダ選択も同じ動作です。

現行の3D画面は、その場で目的地へ旋回してから正面へ前進する共通の航行処理を使います。別の枝へは共通の親フォルダを経由し、別階層のファイルは到着後にプレビューします。高速ワープと2D表示の動作を含む詳細は [共通画面の操作](../README.md) を参照してください。

パンくず・親フォルダへの入口・ブラウザの戻る／進む・別階層の検索結果でも同じ演出を使います。演出中に別の移動要求が来た場合は、最後の要求を優先します。
