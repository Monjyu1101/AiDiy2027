03. セットアップと起動

前提条件

以下のツールが事前にインストールされている必要があります。

ツール バージョン 確認コマンド 備考
Python 3.13 python --version Python 3.13 以上が必要
Node.js v22以上 node --version v22.14.0 / npm 11.3.0 推奨
SQLite - - Pythonに同梱のため個別インストール不要
uv 最新 uv --version 高速パッケージマネージャ
Git 最新 git --version バージョン管理（gitforwindows.org）
バージョン確認コマンド 
python --version
node --version
uv --version
git --version
補足: SQLiteについて

本プロジェクトではSQLiteを使用しますが、SQLiteはPythonに標準で組み込まれているため、 別途インストールする必要はありません。データベースファイルは _data\AiDiy\database.db に自動生成されます。

セットアップ手順

初回のみ実行が必要です。

# プロジェクトディレクトリへ移動
cd workspace/AiDiy2027

# セットアップ実行
python _setup.py

_setup.py が行うこと

このスクリプトは対話形式で、項目ごとに実行するか確認しながら以下を一括処理します。

  1. 共通 — pip/wheel/setuptools/uv のアップグレード、AI CLIツール(Claude Code, Copilot, Codex, OpenCode, Antigravity)の導入
    要件: uv がインストールされていること。未導入の場合: irm https://astral.sh/uv/install.ps1 | iex (PowerShell)
  2. バックエンド(local) — backend_local の uv sync --upgrade（ローカルLLMサーバー、任意でモデル事前ダウンロード）
  3. バックエンド(tools) — backend_tools の uv sync --upgrade とMCP設定ファイルの書き込み（Claude / Gemini向け）
  4. バックエンド(core,apps) — backend_server の uv sync --upgrade
  5. バックエンド(task,team) — backend_taskteam の uv sync --upgrade
  6. フロントエンド(Web) — frontend_web の npm install と npm update
  7. フロントエンド(Avatar) — frontend_avatar の npm install と npm update（必要に応じてElectronバイナリの補完）
  8. コマンド(hermes) — command_hermes の .venv 作成 / uv sync --upgrade / aidiy_hermes 登録試行
補足: PostgreSQL関連処理

DATABASE_TYPE="sqlite" が既定値のため、PostgreSQLユーザー確認・初期データ復元・alembic upgrade head の分岐は通常スキップされます。

補足: データベースとログイン

データベースファイルとテーブルはサーバー初回起動時に自動作成されます（_setup.pyでは作成されません）。
初期データ（admin等のアカウント）はサーバー起動時に「adminが未存在」の場合のみ投入されます。

セットアップ時の注意
  • インターネット接続が必要です（パッケージダウンロードのため）
  • SQLiteデータベースは _data\AiDiy\database.db に作成されます
プロキシ環境の場合

社内ネットワークなどプロキシ環境下では、以下の設定が必要な場合があります。

git config --global http.proxy http://n.n.n.n:nnnn
npm config set proxy http://n.n.n.n:nnnn

※ n.n.n.n:nnnn はプロキシサーバーのアドレスとポートに置き換えてください。

APIキー設定（AI機能を使う場合）

AIコア機能を使用する場合、APIキーの設定が必要です。

設定ファイルの場所

_config/AiDiy_key.json にAPIキーを保存します。
このフォルダは公開リポジトリに含めない方針のため、.gitignore で除外されています。

  • ファイルが無ければ、初回起動時にひな形が自動生成されるため、手動コピーは不要
  • 起動後、AiDiy_key.json 内の各APIキーを設定してください
  • 対応AI: Anthropic Claude, OpenAI, Google Gemini

起動方法

対話形式で起動対象を選び、必要なサービスをまとめて起動します。

# プロジェクトディレクトリへ移動して起動
cd workspace/AiDiy2027
python _start.py

_start.py が行うこと

起動時に次の6項目を順に確認します（既定値は( )内の通り）。

  • バックエンド(local) を起動するか（既定: No、ポート8096、ローカルLLM）
  • バックエンド(tools) を起動するか（既定: Yes、ポート8095、MCPサーバー群）
  • バックエンド(core,apps) を起動するか（既定: Yes、ポート8091/8098）
  • バックエンド(task,team) を起動するか（既定: Yes、ポート8093）
  • フロントエンド(Web) を起動するか（既定: Yes、ポート8090）
  • フロントエンド(Avatar) を起動するか（既定: No、ポート8092）

選択したサービスだけを順番に起動し、起動完了を待機します。command_hermes は常駐サーバーではないため、この対話には含まれません。

_start.py の動作詳細
  • 選択したサービスのポート（8090/8091/8098/8092/8093/8096/8095）を使用中のプロセスを自動で停止
  • Web は http://127.0.0.1:8090、Avatar は http://127.0.0.1:8092 を自動で開く
  • サーバーがクラッシュした場合、監視ループが再起動
  • Ctrl+C で全サーバーを一括停止
起動成功時の表示

選択したサービスに応じて、以下のようなメッセージが表示されれば正常に起動しています。

バックエンド(tools) Swagger UI : http://127.0.0.1:8095/docs
バックエンド(core): http://127.0.0.1:8091/docs
バックエンド(apps): http://127.0.0.1:8098/docs
バックエンド(task,team): http://127.0.0.1:8093/docs
フロントエンド(Web): http://127.0.0.1:8090/
フロントエンド(Avatar): renderer http://127.0.0.1:8092
ポートが使用中の場合

選択したサービスのポート（8090/8091/8098/8092/8093/8096/8095）が既に使用されている場合はエラーになります。
その場合は python.exe や node.exe のプロセスを終了してから再起動してください。

個別起動

開発時にサーバーを個別に起動する場合は以下のコマンドを使用します。

Core サーバー

cd workspace/AiDiy2027/backend_server
.venv\Scripts\python.exe -m uvicorn core_main:app --reload --host 0.0.0.0 --port 8091

Apps サーバー

cd workspace/AiDiy2027/backend_server
.venv\Scripts\python.exe -m uvicorn apps_main:app --reload --host 0.0.0.0 --port 8098

MCP サーバー (backend_tools)

cd workspace/AiDiy2027/backend_tools
.venv\Scripts\python.exe -m uvicorn tools_main:app --reload --host 0.0.0.0 --port 8095

AIタスク・AIチーム統合サーバー (backend_taskteam)

cd workspace/AiDiy2027/backend_taskteam
.venv\Scripts\python.exe -m uvicorn taskteam_main:app --reload --host 0.0.0.0 --port 8093

ローカルLLM サーバー (backend_local、必要時のみ)

cd workspace/AiDiy2027/backend_local
.venv\Scripts\python.exe -m uvicorn local_main:app --reload --host 127.0.0.1 --port 8096

Command Hermes (常駐しないCLI)

cd workspace/AiDiy2027/command_hermes
.venv\Scripts\python.exe cli_main.py

フロントエンド

cd workspace/AiDiy2027/frontend_web
npm run dev

フロントエンド Avatar

# Webモード (Viteのみ)
cd workspace/AiDiy2027/frontend_avatar
npm run dev:renderer

# Electronモード
cd workspace/AiDiy2027/frontend_avatar
npm run dev
個別起動のメリット
  • 変更したサーバーだけを再起動できる
  • ホットリロードが有効になる
  • エラーログを個別に確認できる

部分起動

一部のサービスだけ起動したい場合は、_start.py 実行時の対話で選択します。

cd workspace/AiDiy2027
python _start.py

バックエンド(local)     起動しますか? y/[n]
バックエンド(tools)     起動しますか? [y]/n
バックエンド(core,apps) 起動しますか? [y]/n
バックエンド(task,team) 起動しますか? [y]/n
フロントエンド(Web)     起動しますか? [y]/n
フロントエンド(Avatar)  起動しますか? y/[n]

例: コア業務API(core,apps)だけ動かしたい場合は該当の質問だけ y、残りを n にします。
停止は起動中のターミナルで Ctrl+C を使用します。

VS Code でのデバッグ起動（F5キー）

VS Code を使用している場合、F5キーでデバッグ起動が可能です。

設定ファイル内容
.vscode/launch.json（ルート） _start.py を実行するフルスタック起動設定
backend_server/.vscode/launch.json core_main.py / apps_main.py を個別にデバッグ起動（debugpy）
frontend_web/.vscode/launch.json Vite dev server を起動し、Chrome でデバッグ

動作確認

起動後、以下の手順で動作を確認してください。

1. ブラウザで確認

ブラウザで http://127.0.0.1:8090/ を開いてログイン画面が表示されることを確認します。

2. 初期ログイン

  • ユーザー名: admin
  • パスワード: ********

3. 画面遷移

ログイン後、メニューから各画面に遷移できることを確認します。

4. API確認

以下のURLからSwagger UIでAPIの動作を確認できます。

  • Core API: http://127.0.0.1:8091/docs (C系・A系のAPI)
  • Apps API: http://127.0.0.1:8098/docs (M系・T系・V系・S系のAPI)

ヘルスチェック

バックエンドが起動しているか確認するコマンドです。

curl http://127.0.0.1:8091/core/サーバー状態

完了条件チェックリスト

以下を全て満たせば、環境構築は完了です。

  • 127.0.0.1:8090 が表示される
  • 127.0.0.1:8091/docs が表示される
  • 127.0.0.1:8098/docs が表示される
  • admin でログインに成功する
  • /core/サーバー状態 が応答を返す

停止方法

サーバーを停止する方法は3通りあります。

方法1: Ctrl+C

起動中のターミナルで Ctrl+C を押して停止します。

方法2: タスクマネージャー

  1. Ctrl+Shift+Esc でタスクマネージャーを開く
  2. python.exe と node.exe のプロセスを探す
  3. 選択して「タスクの終了」をクリック → プロセスを終了

方法3: PowerShell

# Pythonプロセスを停止
taskkill /F /IM python.exe

# Node.jsプロセスを停止
taskkill /F /IM node.exe

# Electronが残っている場合
taskkill /F /IM electron.exe
