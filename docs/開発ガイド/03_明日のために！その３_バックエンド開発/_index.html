03_明日のために！その３_バックエンド開発

この章の目的

この章では、M商品を題材に workspace/AiDiy2027/backend_server へバックエンドAPIを追加する手順を学びます。

  • Schema → Model → CRUD → Router の実装順序を理解する
  • AiDiyのPOST中心API設計と共通レスポンス形式に合わせて実装する
  • V系（View系）を生SQLで実装する方針を理解する
  • Swagger UIで動作確認し、不具合の切り分けができる

前提

  • プロジェクトルート: workspace/AiDiy2027
  • バックエンドサーバー: core=8091, apps=8098
  • M商品は apps サーバー（8098）で扱う
  • DBは SQLite（workspace/AiDiy2027/_data/AiDiy/database.db）

実装時の最重要注意

  • 新規M系（例: M○○）を追加したら、backend_server/apps_crud/init.py の init_db_data() へ初期化処理を必ず追加する
  • 初回動作確認で一覧が空にならないよう、可能な限り業務で意味のあるサンプルデータを投入する
  • 初期化処理は冪等に実装し、既存データがある場合は重複投入しない
